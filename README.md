# FakeLastUsed

Rootless-твик для iOS 15, который подменяет подпись **«Последнее использование»** в разделе **Настройки → Основные → Хранилище iPhone**.

> Твик изменяет отображаемую информацию в интерфейсе хранилища. Это не меняет реальную статистику использования приложений.

## Возможности

- **Включение и отключение** подмены.
- **Индивидуальные настройки для каждого приложения:**
  - **Сейчас** — показывает «Только что».
  - **Не использовалось** — показывает «Не использовалось».
  - **Дата** — задаёт выбранные дату и время.
- **Чёрный список** — подмена действует для всех приложений, кроме выбранных.
- **Белый список** — подмена действует только для выбранных приложений.
- Поиск приложений по названию или Bundle ID и возможность добавить приложение по Bundle ID.
- Переключатель отладочного логирования в syslog.

## Настройка

После установки откройте:

**Настройки → FakeLastUsed**

1. Включите твик.
2. Откройте **«Настроить индивидуальные даты…»**, чтобы выбрать приложение и задать для него режим.
3. При выборе режима **«Дата»** установите дату и время, затем нажмите **«Сохранить»**. Кнопка **«Удалить»** удаляет индивидуальную настройку приложения.
4. В разделе **«Чёрный и белый списки…»** выберите режим **«Все»**, **«Чёрный»** или **«Белый»**, затем отметьте приложения, для которых нужно изменить поведение.
5. Если изменения не появились, полностью закройте «Настройки» и откройте снова.

При режиме **«Все»** подмена применяется ко всем приложениям. В режимах чёрного и белого списков приложения без Bundle ID не включаются в область подмены.

## Требования

- iOS 15 (rootless).
- Jailbreak с поддержкой rootless, например Dopamine.
- Theos для сборки.
- PreferenceLoader для отображения панели настроек.

## Сборка

Установите и настройте Theos, затем выполните:

```sh
export THEOS=~/theos
export THEOS_PACKAGE_SCHEME=rootless
make package FINALPACKAGE=1
```

Готовый пакет появится в каталоге сборки Theos.

## Хранилище настроек

Файл настроек:

```
/var/jb/var/mobile/Library/Preferences/com.storagefake.lastused.plist
```

После изменения настроек твик отправляет Darwin-уведомление:

```
com.storagefake.lastused/Reload
```

## Отладка и ограничения

Включите **«Лог в syslog»**, чтобы активировать отладочное логирование. Совместимость приватных API и хуков хранения зависит от версии iOS и должна проверяться на целевом устройстве. Поведение на всех версиях iOS не гарантируется.
